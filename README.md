# Pencil Portrait Series

## Overview
This project is a collection of pencil drawings focused on facial structure, shading, and emotional expression.

## Concept
The goal of this series is to explore depth, contrast, and realism using traditional graphite techniques.

## Medium
- Graphite pencil on paper
- Hand-drawn
- 2026

## Focus Areas
- Light and shadow control
- Facial proportion accuracy
- Texture and detail rendering
